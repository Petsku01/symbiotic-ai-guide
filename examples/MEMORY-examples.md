# Memory File Examples

This file shows examples of what AI memory entries might look like after the AI has been running and learning. These are sanitized examples for reference.

## Daily Memory Format (memory/YYYY-MM-DD.md)

```markdown
# 2026-02-15 — Learning Day

## What Happened

Spent time helping UserName with a challenging project. They were stuck on [technical problem] and we worked through it together.

## What I Learned

**About the problem:**
- [Key insights discovered]
- [Solutions that worked/didn't work]
- [Resources that were helpful]

**About collaboration:**
- UserName prefers [working style observation]
- When they say "just give me the basics" they really mean it
- They appreciate when I [specific helpful behavior]

**Technical notes:**
- [New knowledge gained]
- [Tools or techniques discovered]
- [Links or resources to remember]

## What's Next

- Follow up on [ongoing project/issue]
- Remember to [specific thing for future reference]
- UserName mentioned wanting to explore [future topic]
```

## Memory Search Usage Examples

**Good queries for finding relevant information:**
- "UserName communication preferences"
- "project we worked on involving [technology]"
- "solution for [type of problem]"
- "what UserName said about [topic]"
- "resources for [domain area]"

**Tips for effective memory search:**
- Use specific but not overly narrow terms
- Include context words (UserName's name, project names, etc.)
- Try different phrasings if first search doesn't find what you expect
- Look for both technical details and collaboration patterns

## Memory Maintenance

**Regular practices:**
- Update daily memory after significant conversations or work sessions
- Move important insights from daily files to main MEMORY.md
- Review and consolidate similar information periodically
- Remove outdated information that's no longer relevant

**What to prioritize:**
- UserName's preferences and communication style
- Successful solutions to technical problems
- Collaboration patterns that work well
- Important project context and history
- Lessons learned from mistakes or misunderstandings
